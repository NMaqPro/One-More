ONE MORE - friends test build

Put this whole folder online and anyone can play it, install it and use it offline.
Easiest free options:
  1) Netlify Drop: go to app.netlify.com/drop and drag this folder onto the page. You get a link at once.
  2) GitHub Pages or Cloudflare Pages: upload these files to a new site.

After it is online, friends open the link on their phone:
  iPhone (Safari): Share > Add to Home Screen.
  Android (Chrome): menu > Install app.

Feedback: open index.html in a text editor and fill in FEEDBACK_URL (a Google Form link)
and/or FEEDBACK_EMAIL near the top of the script. Google Forms keep every answer, with a
timestamp, in a spreadsheet. That is your written record.

When you change the game, edit CACHE in sw.js (for example onemore-friends-2) so phones pick up the update.
